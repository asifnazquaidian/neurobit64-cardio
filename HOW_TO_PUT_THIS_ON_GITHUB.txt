HOW TO PUT THIS FOLDER ON GITHUB  (NeuroBit64-Cardio = the heart chip)

Repository name to use (the thesis, the website and the proposals already link to it):
    neurobit64-cardio
Address it will get:
    https://github.com/asifnazquaidian/neurobit64-cardio

STEP 1  Create the repository
  1. Sign in at https://github.com as asifnazquaidian.
  2. Open https://github.com/new
  3. Repository name:  neurobit64-cardio
  4. Description (optional): copy the first line of README.md in this folder.
  5. Choose "Public".
  6. Leave "Add a README file" OFF (this folder already has README.md).
  7. "Choose a license": Apache License 2.0.
  8. Press "Create repository".

STEP 2  Upload the files
  1. On the new repository page press "Add file" > "Upload files".
  2. Open this folder in File Explorer:
         F:\Projects\Chips\NeuroBit64\NeuroBit64-Cardio
  3. Press Ctrl+A to select everything inside it and drag it onto the browser page.
     (Drag the CONTENTS of the folder, not the folder itself, so that README.md is at the top level.)
  4. Wait until the file list has stopped growing. If GitHub lists a second LICENSE, remove the
     small one that came from this folder (click the x next to it) and keep GitHub's.
  5. At the bottom write a message such as "First upload" and press "Commit changes".

STEP 3  Check
  - The page https://github.com/asifnazquaidian/neurobit64-cardio now shows README.md with the description.
  - The link to this repository in your thesis book and on your website now works.

STEP 4 (optional)  Show the Organ Monitor online from GitHub
  1. In the repository: Settings > Pages.
  2. Source: "Deploy from a branch". Branch: main, folder: / (root). Press Save.
  3. After about one minute the app is at
         https://asifnazquaidian.github.io/neurobit64-cardio/app/
  (The same app is also inside your website folder, so it goes online with the Netlify upload anyway.)

LATER CHANGES
  To replace a file: open it on GitHub, press the pencil icon, or use "Add file" > "Upload files"
  again with the new version; GitHub overwrites files that have the same name.

NOTES
  - There is no layout ("gds") job for this repository. The chip is far larger than a Tiny Tapeout
    tile, so nothing will run under the "Actions" tab and that is expected.
  - Do not upload the folder F:\Projects\Chips\NeuroBit64\hec (HEC-64). It stays private.
  - The files "Run Verilog Test.cmd" and "Open ... .cmd" are for your PC; they do no harm on GitHub.
